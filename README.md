# Experiments for Observational Multiplicity paper.

This repository is code for the paper ["Observational Multiplicity" by Erin George, Deanna Needell, and Berk Ustun](https://arxiv.org/pdf/2507.23136).

This contains only code.  To recreate the plots from the paper, the datasets are also needed.  Two of these datasets are publicly available at the following locations:

* [Wisconsin Breast Cancer dataset](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)
* [Fannie Mae Single Family Loan dataset].  This includes code to generate summary statistics, which is necessary to generate the data used in our paper.

To obtain the other two datasets in the paper, please look at the cited papers.
